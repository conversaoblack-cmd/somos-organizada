# Web Interface Guidelines (cópia fixa)

A skill original busca as regras na internet a cada uso. Aqui elas ficam fixas em [regras.md](regras.md),
revisadas antes de entrar no projeto: nada é baixado na hora.

1. Leia as regras em `regras.md` (as instruções de formato de saída estão lá).
2. Leia os arquivos pedidos (ou pergunte quais revisar).
3. Aponte cada problema no formato `arquivo:linha`.
4. Em conflito com `docs/UX.md` ou com o `CLAUDE.md` do projeto, valem os do projeto (ex.: os textos são em pt-BR).
